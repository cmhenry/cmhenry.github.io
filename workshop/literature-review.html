The task

A familiar request

  • "Give me a literature review on content moderation from the last 6 months."
  • We'll do it a few times, each pass adding another piece to the model context.
Pass 0 — Fail naively

Just ask the chatbot

In Claude Desktop (or your favorite tool), paste this and see what comes back:

Give me a literature review of recent political science
work on content moderation from the past 6 months.
Include citations.
What the chatbot can't do

Likely failure modes

  • Stale. Training cutoff predates "recent."
  • Fabricated. Plausible authors and titles that don't exist.
  • Unscoped. No preference for venues you read.
  • Unverifiable. No audit trail behind any citation.
The plan: building a skill

Three pieces of additional context

  • 1 · A real index. OpenAlex — a free, open scholarly catalog.
  • 2 · A custom skill. Tells model how to query OpenAlex.
  • 3 · A canonical reference doc. Tells model what to prioritize.
Piece 1 · OpenAlex

An open index of scholarship

  • 250M+ works. DOIs, authors, venues, citations.
  • Open data. Freemium API.
  • Sign up at openalex.org/settings/api → free key.
  • $1/day free tier. ~1,000 searches/day.
  • Pass as api_key=YOUR_KEY.
Piece 2 · The skill

A reusable recipe

  • Markdown file. Loaded on demand.
  • Encodes how: endpoint, filters, response shape.
  • Triggers on phrases like "literature review."
  • Write once. Reuse.
---
name: openalex-lit-review
description: Search OpenAlex
  for recent scholarly work
  on a topic, with optional
  journal and author scope.
---

# OpenAlex Literature Review

## Endpoint
https://api.openalex.org/works

## Required filters
- from_publication_date
- search OR concept

## Optional filters
- primary_location.source.id
- authorships.author.id

## Always include
api_key=YOUR_KEY

## Output
Title, authors, venue, year,
DOI, abstract, OA link.
Never invent fields.
~/.claude/skills/openalex-lit-review/SKILL.md

Pass 1 — Skill only

Add the recipe

Using the openalex-lit-review skill, find scholarly work
on content moderation published in the last 6 months.

What changes

  • Real DOIs, venues, dates. No hallucinations.
  • But every venue — predatory next to flagship.
  • Triage is still on you.
Pass 2 — + journals

Scope by venue

Using the openalex-lit-review skill and the journals
listed in content-moderation-sources.md, find content
moderation work from the last 6 months.

What changes

  • Limited to JOP, Nature Comms, Political Communication.
  • Triage solved — the doc encodes your standards.
  • Trade-off: misses venues you forgot.
Pass 3 — + authors

Follow the people

Using the openalex-lit-review skill and the journals
AND authors listed in content-moderation-sources.md,
find content moderation work from the last 6 months.

What changes

  • Donnay & Gilardi surfaced in any venue.
  • Working papers, special issues, cross-disciplinary pieces.
  • The doc becomes a research-front sensor.
Reading the passes

What each piece fixes

  • Pass 0 — fabrication.
  • + skill — real citations, no scope.
  • + journals — venue scope.
  • + authors — venue scope plus watch-list.
Takeaways

What we actually built

  • A skill is a reusable recipe.
  • A canonical doc is taste, written down.
  • The chat box is the wrong tool for anything you'd cite.
  • Pattern generalizes — archives, datasets, court filings.
Take home
