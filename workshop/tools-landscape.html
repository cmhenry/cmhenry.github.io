The landscape

Three shapes of tool

  • Desktop apps — chat windows, with extras bolted on.
  • Harnesses — a terminal where the model can read and write your files.
  • Agentic systems — you give a goal, walk away, come back later.
  • Same underlying models. Very different workflows.
What actually differs

Three axes

  • Autonomy — how many steps it takes without you.
  • Access — what it can read, write, and run.
  • Latency — seconds, minutes, or hours to a result.
  • Pick the tool by which axis your task lives on.
Category 1
PART 1 OF 3

Desktop apps

The chat window — and what's been bolted onto it.
Chat + Projects

The familiar one

  • One conversation. You type, it answers. No file access.
  • Projects add persistent instructions and a small file store.
  • Good for: drafting, brainstorming, one-off questions, reading a PDF you pasted in.
  • Limit: every session starts cold. The model doesn't touch your machine.
Cowork

Chat, plus your folder

  • Same chat interface — but pointed at a folder on your disk.
  • The model can read, write, and edit files there. It runs code in a sandbox.
  • Connectors plug in: Gmail, Slack, Drive, Obsidian, whatever has an MCP server.
  • Good for: anything where the answer is a file, not a message.
  • This is what we're running right now.
Scheduled · Dispatch

Chat without you in the chair

  • Scheduled tasks — run a prompt on a cron. "Every Monday, summarize my inbox."
  • Dispatch — fire off a long job in the background, come back to the result.
  • Same desktop app. The conversation just doesn't need you in it.
  • Useful when the work is recurring or slow, not when you're iterating.

Harnesses

The model, in your terminal, with your tools.
What's a harness?

A loop, not a chat

  • A CLI program that runs an agentic loop: think → act → observe → repeat.
  • "Act" means: edit files, run shells, call APIs, search the web.
  • You watch the loop. You can interrupt, redirect, or approve each step.
  • Born for coding, but works for any task that lives in files.
Claude Code

Anthropic's harness

  • Terminal app. Lives in a directory. Reads and writes its files.
  • Tools: bash, file edits, web fetch, subagents, MCP connectors, skills.
  • You can stop it, branch it, run several in parallel on different worktrees.
  • Same engine as Cowork — different surface. The CLI gives you more control and visibility into the loop.
Codex

OpenAI's harness

  • Same shape as Claude Code: terminal, files, agentic loop.
  • Powered by OpenAI's models. Different defaults, different feel.
  • Useful when you want a second opinion from a different model family.
  • The interfaces are converging — skills transfer between them.
Open source harnesses

aider, opencode, Cline, and friends

  • Community-built CLIs you point at any model API.
  • Bring-your-own-key: Claude, GPT, Gemini, or a local open-weight model.
  • Less polish, more control. Audit the loop. Swap the model.
  • Right choice if you need to run on local weights — privacy, cost, reproducibility.

Agentic systems

Hand off a goal. Come back to a result.
What's an agentic system?

Long horizon. No human in the loop.

  • Same agentic loop as a harness — but runs in the cloud, for hours.
  • You set the goal, it plans, executes, recovers, and reports back.
  • Often has a browser, a virtual machine, and broad tool access.
  • You're not watching it work. You're reviewing what it did.
The players

Three to know

  • OpenClaw — Anthropic's autonomous agent. Browser + VM + long-running tasks.
  • Hermes — independent agentic system. Same shape, different stack.
  • Gemini Spark — Google's. Tight integration with Workspace and Search.
When to reach for one

The task fits the shape

  • Multi-hour work you've fully scoped (not exploration).
  • Steps you could write down, but don't want to babysit.
  • You can verify the output afterwards without re-doing the work.
  • Bad fit: anything where the right answer requires your judgement mid-flight.
Picking one

Match the tool to the task

  • Thinking with words? Chat window.
  • Producing a file? Cowork.
  • Editing a codebase or running scripts? A harness.
  • Recurring or scheduled? Scheduled tasks.
  • Long-horizon, fully delegated? An agentic system.
What we'll use today

From here on, mostly one of them

  • Cowork: for the literature review and synthetic peer review.
  • Everything else on this map: in your back pocket for the next time you need it.
